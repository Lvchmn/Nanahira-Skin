Nanahira Skin v0.2.4

アクセサリー1個でななひらの見た目に切り替えるMODです。通常アクセサリースロット・見た目用アクセサリースロットの両方に対応します。ステータス効果はありません。木材10個で作成でき、以前のバージョンのアクセサリーもそのまま使えます。

対象・ビルド確認環境：Terraria 1.4.4.9 / tModLoader v2026.8.3.0。

アニメーション

ゲームが計算した `Player.legFrame` を脚に、`Player.bodyFrame` を胴体・頭・後ろ髪に使います。独自タイマーで全身を一緒に動かす方式ではなく、ゲーム側の動作と速度に合わせて切り替えます。これにより、歩きながら道具を使う場合も、脚と上半身がそれぞれの動きを続けます。

コマ番号は上から0始まりです。実際に選ばれるコマは装備やゲーム側の状態によって異なります。

| コマ | 主な用途 |
| --- | --- |
| 0 | 通常立ち |
| 1〜4 | アイテム使用・構えなどの上半身ポーズ |
| 5 | 通常のジャンプ・落下 |
| 6 | 飛行などの特殊な上半身ポーズ |
| 7〜19 | 歩行・走行など |

ジャンプと落下はゲームが選ぶ既存のコマを使います。別々の専用アニメーションを追加したわけではありません。静止中に自動で呼吸する待機アニメーションも、このシートには含まれていません。
